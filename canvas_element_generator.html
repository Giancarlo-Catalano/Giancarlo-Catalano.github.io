Canvas Content Generator

Create interactive and colourful HTML elements for your Canvas pages.

How to use this tool

Canvas LMS allows you to create rich content, but sometimes the standard text editor is not enough. This tool generates the exact HTML code you need for interactive sections, warning boxes, and styled tables.

  1. Select the type of element you want to create using the tabs above.
  2. Fill in your text and choose your styling options. The preview will update automatically at the bottom of the page.
  3. When you are happy with the preview, click the "Copy HTML to Clipboard" button.
  4. Go to your Canvas page and click "Edit".
  5. Switch to the HTML editor by clicking the "</>" icon (usually at the bottom right of the text editor).
  6. Paste your code in the desired location and save the Canvas page.

Note: You will not be able to edit the advanced styling of these elements using the normal Canvas text editor once pasted. If you need to make changes, it is easiest to recreate the element here and paste it again.
