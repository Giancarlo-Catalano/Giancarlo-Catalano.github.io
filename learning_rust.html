This is my own personal guide to learning Rust. The guides I find on the Internet are still too wordy.
  1. The default behaviour of variable assignment is to move (i.e. copied and the original variable is unusable) the value being assigned if it is not a primitive type.
    • let a = vec![1, 2, 3]; let b = a; means that the vector has been moved to b and that a is not valid anymore.
    • fn do_thing(x: notPrimitive) {...}; let a = notPrimitive{}; do_thing(a); means that the value in a has been moved to x within do_thing.
    • This includes for loops! for thing in things {...} will move things into something else, and then you can't use it anymore!! You need to use .iter()
  2. String and &str. String can be mutable and heap allocated. &str is immutable and a pain to work with.
    • String cannot be moved implicitly, you need to call .clone()
    • String can be used as string builder, even though there is a string_builder
  3. If you don't put the semicolon on the last part of a function, it is assumed that it is returned.
  4. The "normal way" of printing things is via println!("{}", thing), but that only works if thing implements Display.
    • If you want to print without faff, just use {:?}, BUT it needs to implement Debug!! 
      •       #[derive(Debug, Clone, Copy)]
      struct ContinuousVariable {
          lower_bound: f64,
          upper_bound: f64
      }
  5. To make something properly printable, you need to implement the Display trait (interface). 
          
    
      impl fmt::Display for ContinuousVariable {
    
          fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
    
              write!(f, "[{}, {}]", self.lower_bound, self.upper_bound)
    
          }
    
      }
